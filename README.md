# Animalife Paraguay

Pet products marketplace for Paraguay: responsive web shop + Expo mobile app sharing the same domain contracts.

## MVP
- Responsive product catalog and product detail pages
- Cart and checkout flow
- Mock Paraguay payment abstraction (ready for provider adapters)
- Mock delivery/shipping abstraction
- Customer account/order history demo
- Admin product management demo
- Shared TypeScript domain package for web/mobile/backend boundaries

## Run
npm install
npm run dev:web

For mobile:
npm run start:mobile

The prototype uses mock/local data. Never commit real payment, shipping, auth, database, or API credentials.
